Senja Amphibi — a 3D seaplane game over an Indonesian archipelago at golden hour. Fly rings, hop between lagoon docks, drop mail, rescue a sailor. Chase and cockpit views, live instruments, fuel and damage.

## Missions

Four sorties, 180 seconds each — pick one on the title screen:

1. **Ring Run** — fly through 6 rings in order (+100 each).
2. **Island Hop** — water-land at 3 lagoon docks (+150 per clean landing).
3. **Mail Drop** — drop crates on 3 village docks (+120 each).
4. **Rescue Run** — water-land at the raft, pick up the sailor (+100), deliver him to Main Dock (+200).

Land gently: under 85 km/h with a sink under 6 m/s, or the hull takes damage. Watch the fuel — an empty tank ends the sortie.

## Controls

W/S throttle · A/D turn · hold mouse to climb · Space drops a crate · C cockpit/chase view · P pause · R restart · 1–4 pick a mission.

## Run it

```sh
node serve.ts
```
Then open http://localhost:8080.
